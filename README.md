# SQL Development Exercises

SQL practice scripts for schema creation, data integrity, indexes, queries, nested queries, and triggers.

> Academic context: this directory contains course lab or coursework solutions.

## Scripts

- `Create.sql`: schema creation
- `Integrity.sql`: integrity constraints
- `index.sql`: indexes
- `select.sql` and `Nested_queries.sql`: queries
- `trigger.sql`: triggers

## Use

Run `Create.sql` first in a compatible relational database, then execute the remaining scripts in the order needed for the topic being studied. Review the script syntax and adapt it to your database product where necessary.
